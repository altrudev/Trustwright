# Contributing

Thank you for wanting to help. Trustwright is in design and not yet accepting code contributions.

When it opens:

- **Contributor licence agreement.** Trustwright is dual-licensed (see [LICENSING.md](LICENSING.md)), so every contributor signs an agreement that lets ALTRU.dev offer contributions under both licences. The agreement text is still being written.
- **Zero dependencies.** Go standard library and vanilla JavaScript only. No frameworks, no build step.
- **Every change is proven.** A change ships with a test that fails without it and passes with it.
- **Plain language** in the interface and in docs.

Bug reports and ideas are welcome now: open an issue.
