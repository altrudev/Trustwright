# Trustwright™

**See it, fix it, prove it.**

Trustwright maps a system you are building, such as AI agents and the tools they can reach, federated servers, or programs that exchange messages, and checks it against rules: who may do what, which messages must be signed, which units and versions must match.

When a rule breaks, it shows you where on the map and proposes a fix. Most fixes come from a built-in catalogue of proven patterns, so no AI is needed. You can also connect your own AI model, cloud or local.

Nothing changes in your code until you pick a fix. Every proposed fix is checked first:

1. the broken rule now passes,
2. nothing else breaks,
3. a new test fails on the old code and passes on the new code, and
4. every change in behaviour is listed and expected.

You preview the change, choose it, and it arrives as a pull request with a signed record of what was checked.
